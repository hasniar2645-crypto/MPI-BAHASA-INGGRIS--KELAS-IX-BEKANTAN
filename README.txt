MPI: Exploring Fauna of Indonesia — Unit 1: Bekantan

CARA MENJALANKAN OFFLINE
1. Ekstrak file ZIP.
2. Buka folder MPI_Exploring_Fauna_Bekantan.
3. Klik dua kali index.html, lalu buka dengan Chrome, Edge, Firefox, atau browser modern.
4. Navigasikan materi menggunakan tombol bagian di atas.

CARA MEMBUAT ONLINE
Unggah index.html ke layanan hosting statis seperti GitHub Pages, Netlify, atau layanan hosting sekolah. Karena paket ini menggunakan satu file HTML tanpa dependensi eksternal, materi dapat dijalankan secara offline maupun di-host secara online.

ISI
- Apersepsi
- Asesmen awal
- Materi pokok dan kosakata
- Simulasi deskripsi
- Kuis dengan umpan balik dan skor
- Asesmen akhir dengan skor
- Refleksi

Catatan: Ilustrasi hewan berupa emoji, bukan foto asli. Hasil kuis dan refleksi berjalan di browser; tidak dikirim otomatis ke guru. Guru dapat mengedit index.html menggunakan editor teks.
